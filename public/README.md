# Street Flavor — Interactive Street-Food Showcase

A cinematic, interactive street-food showcase featuring stacked subs, smashed burgers, fire-baked pizza slices, loaded tacos, and sweets with choreographed scene transitions.

## 🍔 Features
- **Dynamic 3D-feel Scene Transitions**: Smooth interactive transitions between featured street food items.
- **Interactive Ingredients & Layers**: High-resolution floating ingredient layers choreographing around hero dishes.
- **Responsive Design**: Tailored visual experience for mobile, tablet, and desktop viewports.
- **Zero-Dependency Local Server**: Built-in lightweight HTTP server ready for local development or preview.

## 🚀 Quick Start

### 1. Run Locally
To run the project locally on `http://localhost:3000`:
```bash
npm start
```
or directly with Node.js:
```bash
node server.js
```

### 2. Static Hosting
The project is completely static and ready for direct deployment on **GitHub Pages**, **Vercel**, **Netlify**, or any static hosting provider.
